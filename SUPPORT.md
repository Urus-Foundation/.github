## Getting Help

### GitHub Discussions
For questions, ideas, and community conversations:
- [Start a Discussion](https://github.com/Urus-Foundation/Urus/discussions)

### Bug Reports
If you've found a bug:
- [File a Bug Report](https://github.com/Urus-Foundation/Urus/issues/new?template=bug_report.yml)

### Feature Requests
Have an idea for Urus?
- [Submit a Feature Request](https://github.com/Urus-Foundation/Urus/issues/new?template=feature_request.yml)

### Security Issues
Found a security vulnerability?
- **Do NOT open a public issue.** See our [Security Policy](SECURITY.md).

### Email
For anything else:
- [urusfoundation@gmail.com](mailto:urusfoundation@gmail.com)

## Contributing

Want to help improve Urus? See our [Contributing Guide](CONTRIBUTING.md) to get started.
